# Data sources

Every outside source the project uses, its license, and how it's credited. Restricted inputs (none yet) live in `pipeline/private/`, which is never committed.

| Source                                                                                                         | Used for                                                                                                                                                                                                                                                                      | License      | Credit                                                                                                                                                                                                              |
| -------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [nflverse play-by-play](https://github.com/nflverse/nflverse-data) (regular seasons 2022–2025)                 | Calibration targets and the engine's fitted shapes (`calibration/targets.json`, built by `npm run pipeline -- calibration`)                                                                                                                                                   | CC-BY-4.0    | "Play-by-play data from nflverse (nflverse.com), CC-BY-4.0"                                                                                                                                                         |
| [nflverse participation](https://github.com/nflverse/nflverse-data) (2023–2025)                                | Formations, personnel, men in the box, pass rushers, coverage shells, pressure, time to throw, routes (`calibration/matchups.json`, built by `npm run pipeline -- matchups`)                                                                                                  | CC-BY-4.0    | "Participation data from nflverse (nflverse.com), CC-BY-4.0"                                                                                                                                                        |
| [nflverse participation and play-by-play](https://github.com/nflverse/nflverse-data) (2022–2025)               | Snap shares by depth, in-game injury rates and games missed, real season leaderboards, EPA and success rate (`calibration/people.json`, built by `npm run pipeline -- people`). Player names in the raw files are used only in memory to match injuries; the output has none. | CC-BY-4.0    | "Data from nflverse (nflverse.com), CC-BY-4.0"                                                                                                                                                                      |
| [FTN charting via nflverse](https://github.com/nflverse/nflverse-data) (2022–2025)                             | Play-action, screen, RPO and QB-sneak rates, drops, throwaways (`calibration/charting.json` only)                                                                                                                                                                             | CC-BY-SA-4.0 | "Charting data by FTN Data via nflverse, CC-BY-SA-4.0". The numbers derived from it stay in `calibration/charting.json`, which is shared under the same CC-BY-SA-4.0 license; nothing else in the repo is affected. |
| NFL rulebook, tie-breaking procedures, and rule-change announcements (nfl.com, operations.nfl.com, team sites) | League rules in `rules/` (each block cites its source)                                                                                                                                                                                                                        | Facts        | Cited per rule                                                                                                                                                                                                      |

Downloaded files go in `pipeline/cache/` (git-ignored) and are re-downloaded when missing.
