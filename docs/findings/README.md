# Findings

Questions answered by running the league many times (Phase 17). Each finding names its experiment file and seeds, so it can be rerun with `npm run sim -- --experiment experiments/<file>.json`. The same numbers, charts and conclusions are on the app's Experiments page (`/experiments`).

1. [How random is a single-elimination playoff?](01-playoff-randomness.md)
2. [A great head coach vs a great quarterback](02-coach-vs-quarterback.md)
3. [Aggressive vs conservative fourth-down coaches](03-fourth-down-coaches.md)
4. [Cap-aggressive vs conservative general managers](04-cap-aggressive-gms.md)
5. [Draft and develop vs free-agency spending](05-draft-vs-free-agency.md)

Results that come from the private rating file stay on the machine that ran them and aren't committed: the alternate-histories experiment (`title-odds-2026`: the 2026 season replayed 1,000 times from the real start, with each team's chance of the title, the final and the playoffs). Its page is on the Experiments list on the machine that has the real league.
